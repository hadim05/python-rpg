# Python RPG Game

A text-based role-playing game built using Python.

This project was created to practise object-oriented programming,
working with classes, managing game data, and building a complete
program independently. 

## Features

- Two playable character classes: Warrior and Mage
- Turn-based combat against enemies
- Experience points and character levelling
- Gold and an in-game shop
- Inventory and equipment system
- Save and load game progress using JSON
- Interactive text-based menu 
## How to Run

### Requirements
- Python 3 installed

### Instructions

1. Download or clone this repository.
2. Open a terminal inside the project folder.
3. Run the following command:

```bash
python rpg_game.py
```

4. Follow the on-screen menu to play the game.
